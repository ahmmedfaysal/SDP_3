# EduNexus - A central point for study resources

**EduNexus** is a platform designed to connect students and provide a seamless solution for sharing and accessing class notes and study resources. New students often face challenges in obtaining high-quality notes and this platform bridges the gap by enabling both new and old students to upload, access, and evaluate notes. The system identifies and ranks the best notes based on quality and relevance, ensuring that all students benefit from shared resources. Each user has a personalized account that allows them to sign in, sign out, and update their information on this platform. Also they can  contribute to the platform with notes and resources.


---

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Figma for design
- MongoDB for database

---

## 🌟 Features
- User sign-in and login functionality for personalized access.
- Option to visit the platform as a guest for quick browsing.
- Dedicated page for uploading notes.
- View and manage a list of uploaded notes.
- Browse other users' uploaded notes for shared learning.
- Explore a comprehensive blog list on study topics.
- Advanced search functionality for notes and blogs.
- Update user information for profile management.
- Note ranking system based on upvotes and downvotes.
